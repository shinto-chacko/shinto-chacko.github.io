# DoorNotice website

This is the static public website for DoorNotice, the primary housing-society app, with DoorDues presented as an optional maintenance-billing add-on. The complete DoorDues product details are available on the separate `doordues.html` page linked from the site.

The site's custom domain is `www.doornotice.com` (`CNAME`). For GitHub Pages, configure `www` as a CNAME to `shinto-chacko.github.io`. To make the apex domain `doornotice.com` resolve to the same site, configure its A records to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, and `185.199.111.153`. Then confirm `www.doornotice.com` in the repository's **Settings → Pages** and enable HTTPS after DNS verification. The website source and its clean illustrative preview do not include the supplied proposal or raw app screenshots.

Keep proposal PDFs, society records, resident details, sample bills, WhatsApp sender files, and `whatsapp_session` data out of this public repository.
